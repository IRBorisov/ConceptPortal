# Профиль ЯРЭ

Читай только при разборе языка родоструктурной экспликации. Эти средства не являются универсальными для других формальных языков.

## Уровень рассмотрения

ЯРЭ рассматривается как язык построения явной системы понятий с формальными определениями, связями и ограничениями, допускающей интерпретацию и проверку. Одна конкретная КС на ЯРЭ является примером применения, а не описанием устройства языка.

Ступени, М-граф и специальные классы конституент раскрываются в профиле и КМ ЯРЭ. Не объявляй их универсальными понятиями общей КС «Формальный язык». Для множества `X#` используй термин «базисное множество»; `X#`, `C#`, `S#` относятся к неопределяемым понятиям.

## Таблица отождествлений

При наличии экспликаций задействованных в синтезе КС проверяй таблицу отождествлений средствами `@rsconcept/domain`. В библиотеке используется `SubstitutionValidator` из публичного экспорта `@rsconcept/domain/library/oss-api`.

```ts
import { SubstitutionValidator } from '@rsconcept/domain/library/oss-api';

const validator = new SubstitutionValidator(schemas, substitutions);
const valid = validator.validate();
const diagnostics = validator.errors;
```

На вход нужны проанализированные исходные КС с типизациями и графами зависимостей и таблица по идентификаторам конституент. Одной таблицы недостаточно.

Анализируй и итог проверки, и весь список диагностик. Успешный результат может сопровождаться диагностикой несовпадения формальных определений. Не считай `true` эквивалентом пустого списка диагностик.

Валидатор проверяет, в частности, допустимость типов сопоставляемых конституент, согласованность типизаций, циклы в зависимостях типизаций и логические циклы формальных определений после подстановок. Он не доказывает предметное тождество сущностей и пригодность их отождествления для задачи.

Сначала проверь документацию и фактический контракт доступной версии библиотеки. В репозитории Portal смотри:

- `rsconcept/domain/src/library/oss-api.ts` и `oss-api.test.ts`;
- `rsconcept/rstool/docs/DOMAIN.md`, раздел «Синтез»;
- `rsconcept/rstool/skills/rstool/SKILL.md` для работы с библиотекой, моделями и Portal.

Этот профиль не предписывает строить новую КС ради разбора другого языка. Если библиотека или необходимые экспликации недоступны, обозначь границы проверки и продолжай содержательное исследование доступными средствами, не заявляя выполненной инструментальной валидации.
