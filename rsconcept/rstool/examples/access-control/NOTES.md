# «Ролевой доступ»: иерархия ролей и разделение обязанностей

Пример по требованиям к ПО: v1 — роли, иерархия, назначенные и эффективные права, разделение обязанностей; v2 — временные роли. Метод — [`docs/METHOD.md`](../../docs/METHOD.md); требования → бриф — [`docs/REQUIREMENTS.md`](../../docs/REQUIREMENTS.md).

Файлы: [`requirements-v1.md`](requirements-v1.md), [`requirements-v2.md`](requirements-v2.md), [`brief-v1.json`](brief-v1.json), [`brief.json`](brief.json), [`build-rsform.ts`](build-rsform.ts), сессии v1 и v2, [`anti/`](anti/).

## Главные решения

- **Иерархия — отношение, не дерево (`DC1`).** Роль может входить в несколько старших; дерево — вид вместо рода.
- **Права пользователя выводятся (`DC2`).** Структура «права пользователя» `S#` сделала бы схему «зелёной», но права разошлись бы с ролями. Назначенные (`F5`) и эффективные (`F6`) права — производные, и это главное различение (`V1`).
- **Разделение обязанностей — по эффективным ролям (`DC3`).** Требование говорит «в том числе через иерархию». Проверка только прямых ролей проще, но пропускает конфликт через наследование — антипример `weakened`.
- **Отсутствие аксиомы симметричности несовместимости (`DC4`)** — решение: `A2` проверяет пару в любом порядке.

## v2

Временные назначения — отдельная структура `S5` с периодом и текущий день `S6` (`DC7`): `S1` и сценарии v1 не меняются. Прямые роли `F2` переопределены новым решением `DC6` (`supersedes: DC2`); без временных назначений формула совпадает с v1.

## Антипримеры

| Снимок                                  | Ошибка                                         | Что ловит                                        |
| :-------------------------------------- | :--------------------------------------------- | :----------------------------------------------- |
| [`weakened.json`](anti/weakened.json)   | разделение обязанностей только по прямым ролям | негатив `SC3`: конфликт через иерархию не пойман |
| [`collapsed.json`](anti/collapsed.json) | эффективные права `F6 := F5` (назначенные)     | `SC1`: права `ann`; различение `V1`              |
