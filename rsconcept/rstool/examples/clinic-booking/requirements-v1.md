# Требования «Запись к врачу», v1 (фрагмент)

1. У врача одна или несколько специальностей.
2. Врач ведёт приём в слотах: слот — время в конкретный день (начало и конец в минутах от начала дня). Слоты одного врача не пересекаются.
3. Пациент записывается на свободный слот. На один слот — не больше одной записи.
4. Пациенту показываются слоты, доступные для записи: свободные и не пересекающиеся по времени с его другими записями.
5. Приём состоялся, если пациент пришёл по записи. Состоявшийся приём бывает только по записи.
6. Пациент получает SMS-напоминание за сутки.
7. Оплата приёма — через кассу или онлайн.
