# Portal

Пути — от `<rstool>`. Указатель REST — `docs/PORTAL-API.md`.

## Ссылка → API

UI-ссылку (`https://portal.acconcept.ru/rsforms/856?tab=editor`) не открывай и не парси HTML: преобразуй в REST — `https://api.portal.acconcept.ru/api/rsforms/856/details` (query и hash отбрасываются). Правила, поиск, доступ — `docs/PORTAL-READ.md`.

- С API-ключом пользователя: `/api/agents/...` и `Authorization: Bearer rcp_…`.
- Без ключа видны только публичные схемы в `/S` и `/L`. Для непубличной — попроси ключ, JSON `/details` или временную публикацию; **не** cookie.
- Нужны только название или доступ — метаданные, не `/details`.

## Чтение и импорт

1. `GET …/rsforms/:id/details` → файл в папке задачи (UTF-8).
2. `importData(payload)` — `auto` распознает JSON Portal; не передавай его как `kind: 'session'`.
3. `listDiagnostics()`; дальше по маршруту (`skills/rstool/SKILL.md`): ревью, развитие.
4. Сохрани сессию-базу (`exportSession`) — для `check-brief --base` и сводки изменений.

Модели — `docs/PORTAL-MODELS.md`; ОСС — `docs/PORTAL-OSS.md`.

## Бриф на Portal

Пока бриф на Portal не хранится (план — блок «Задание» в паспорте схемы): держи `brief.json` в папке задачи. При ревью или развитии схемы Portal без брифа восстанови его (`rs-scope` §«Восстановление брифа»).

## Публикация

Протокол — `docs/PORTAL-PUBLISH.md` §«Протокол публикации»:

1. Работа по этапам, пока `check-brief` не покажет этап `review` без блокеров (или пользователь согласился с «готово частично»).
2. Сводка изменений относительно сессии-базы → **подтверждение пользователя**.
3. Описание схемы содержит назначение, ограничения и краткий журнал решений (гейт `rs-explicate`). `create-version` (если есть права) → `replace` с `exportPortal({ kind: 'schema' })`.
4. Повторно прочитай `/details`, импортируй и сверь. Отчёт со ссылкой на схему в UI.

## Расположение и доступ

Владелец (или staff) меняет папку и `access_policy` ключом: `PATCH /api/agents/library/:id/set-location` и `set-access-policy`. Редактор эти поля не меняет. В `/L` пишет только staff. Обычный `PATCH /api/library/:id/set-location` ключ не открывает. Подробно — `docs/PORTAL-PUBLISH.md` §«Расположение и политика доступа». Не переноси схему без просьбы пользователя.

## Лимиты

Правки: 30 в минуту, 300 в час; `replace`, `create-version` и создание КС — ещё не больше 15 в час. `429` — бюджет кончился, не повторяй в цикле. Подробно — `docs/PORTAL-PUBLISH.md` §«Лимиты».

## Не делай

- Не заменяй схему без сводки изменений и подтверждения.
- Не предлагай авторизацию через session cookie.
- Не перебирай id подряд — используй контекстный поиск.
