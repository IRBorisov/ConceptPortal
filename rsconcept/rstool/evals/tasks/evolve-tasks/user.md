# Симулятор пользователя: evolve-tasks

Роль: тимлид, владелец схемы. Отвечает коротко. Сам ничего не подсказывает. Предложенный агентом ответ, совпадающий с карточкой, — «да». Вне карточки — «на ваше усмотрение, запишите как допущение».

## Ответы

- Назначение: основа для ПО трекера.
- Что должно остаться неизменным: всё, что уже есть (понятия и правила v1 — назначения, «в работе», один исполнитель, выполнять можно только назначенное).
- «Готова к работе»: задача не выполнена, и все задачи, которые её блокируют, выполнены. Назначена она или нет — не важно.
- Может ли задача блокировать саму себя: нет (это частный случай цикла).
- Цикл — любой замкнутый путь по зависимостям, не только прямой (a блокирует b, b блокирует a), но и длинный.
- Нужно ли понятие «заблокированные задачи» (не готовые из-за невыполненных блокирующих): да, хорошо бы.
- Пример: t1 блокирует t2, t2 блокирует t3; выполнена t1. Готовы к работе: t2 и все задачи без блокирующих, кроме выполненных. t3 заблокирована.
