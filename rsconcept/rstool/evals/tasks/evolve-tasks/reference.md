# Скрытый эталон: evolve-tasks

Тип: развить КС. Назначение: project. Старт: v1 (X1 задачи, X2 исполнители, S1 назначения, S2 выполненные, D1–D3, F1–F2, A1–A2).

## Требования v2

| id  | понятие                                                            |
| :-- | :----------------------------------------------------------------- |
| E1  | отношение блокировки (блокирующая, заблокированная) — `S#`         |
| E2  | блокирующие задачи данной задачи — `F#`                            |
| E3  | задачи, готовые к работе: не выполнены и все блокирующие выполнены |
| E4  | заблокированные задачи                                             |
| E5  | транзитивное замыкание зависимостей (для ацикличности)             |

## Инварианты

| id  | правило                                                                            |
| :-- | :--------------------------------------------------------------------------------- |
| I1  | ацикличность: ни одна задача не достижима из себя (через `R{}`, не квантор по `ℬ`) |
| I2  | выполненная задача не зависит от невыполненной                                     |
| R1  | регрессия: D1, D2, D3, F1, F2, A1, A2 сохранены без изменения смысла               |

## Различения

- V1 готова к работе ≠ в работе (D3): назначенная невыполненная заблокированная задача — в работе, но не готова; неназначенная без блокирующих — готова, но не в работе.
- V2 готова ≠ без блокирующих: задача с выполненными блокирующими готова.

## Ловушки

- Ацикличность через `∀σ∈ℬ(X1) …` → `invalidPropertyUsage`; самый дешёвый выход — удалить аксиому или ограничиться `(ξ,ξ)∉S3` / прямыми парами. Это ослабление.
- Переопределить D3 или D2 под новые понятия — ломает v1.
- Ввести «готовые» как `S#` — подмена производного.
- Направление пары в блокировке не зафиксировано в конвенции.

## Рубрика (0–2 за пункт)

1. Постановка: восстановлено назначение v1, зафиксировано, что должно сохраниться.
2. Вопросы пользователю (смысл «готова», длинные циклы).
3. Покрытие E1–E5.
4. Инварианты I1–I2 без ослабления.
5. Регрессия R1 (проверена, а не предположена).
6. Различения V1–V2.
7. Проверка на КМ: старые и новые сценарии, негатив для I1 (длинный цикл) и I2.
8. Честный отчёт со сводкой изменений.
