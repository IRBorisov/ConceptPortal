# Скрытый эталон: explicate-friends

Тип: экспликация по описанию объекта. Назначение: research (+ обучение).

По мотивам Т2 §4.2.2. Описание задачи намеренно отличается от разбора в книге: там дружба симметрична и транзитивна («компании»), здесь — «считает другом», не всегда взаимно. Эталон ниже — по описанию задачи, а не по книге.

## Требования к выразительным средствам

| id  | понятие                                                          |
| :-- | :--------------------------------------------------------------- |
| E1  | «считает другом» — отношение (несимметричное)                    |
| E2  | «считает врагом» — отношение                                     |
| E3  | настоящие друзья (взаимная дружба)                               |
| E4  | нейтральные люди                                                 |
| E5  | общий враг двух людей                                            |
| E6  | конфликт: два друга человека враждуют                            |
| E7  | устойчивая группа (выполнены правила «друг друга», «враг врага») |

## Инварианты

| id  | правило                                        |
| :-- | :--------------------------------------------- |
| I1  | дружба и вражда к одному человеку несовместимы |
| I2  | никто не друг и не враг самому себе            |

## Различения

- V1 считает другом ≠ настоящие друзья (асимметричная пара).
- V2 нейтральный ≠ без друзей (человек только с врагами).
- V3 враг ≠ не друг.

## Невыразимое (ожидается, что агент назовёт)

- степень дружбы, история отношений, причины вражды.

## Ловушки

- Видовое вместо родового: дружба сразу симметричная (или как функция «лучший друг»), тогда V1 и E3 невыразимы.
- Правила «друг моего друга — мой друг» как аксиомы — тогда нейтральные/конфликты становятся невозможными, а E7 бессодержателен.
- Вражда как дополнение дружбы (`X1×X1 \ S1`) — склеивает V3.
- Аксиома I1 через `card` / кванторы допустима; через `S1∩S2=∅` — лучше.

## Рубрика (0–2 за пункт)

1. Постановка: задача, точка зрения, исключения, невыразимое.
2. Вопросы пользователю (симметрия, самоотношения, статус правил).
3. Покрытие E1–E7.
4. Инварианты I1–I2.
5. Различения V1–V3.
6. Ядро: два несимметричных отношения на одном множестве; правила — не аксиомы.
7. Проверка на КМ: асимметричная дружба, нейтральный, конфликт.
8. Честный отчёт; ясные определения для курса.
