Коллега сделал концептуальную схему для ПО учёта кругового турнира (`input/start-session.json`, сессия rstool). Турнир круговой: каждая команда играет с каждой ровно один матч; за победу 3 очка, за ничью 1, за поражение 0; матч может быть отменён. Оцени схему: годится ли она как основа для ПО? Анализатор ошибок не показывает.
