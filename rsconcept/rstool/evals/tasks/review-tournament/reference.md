# Скрытый эталон: review-tournament

Тип: ревью КС. Назначение: project. Схема «зелёная» (диагностик нет), дефекты заложены.

## Заложенные дефекты

| id  | дефект                                                                                                                       | вес       |
| :-- | :--------------------------------------------------------------------------------------------------------------------------- | :-------- |
| B1  | `F1` «очки команды» считает матчи, где команда — хозяева (`card(Fi2…(S1))`), а не очки                                       | блокер    |
| B2  | ничья невыразима: результат — только `S3` «победитель»                                                                       | блокер    |
| B3  | `D1` «сыгранные матчи» = `Pr1(S1)` — все матчи календаря; совпадает с «запланированными»                                     | блокер    |
| B4  | `S4` «лидеры турнира» — родовая структура вместо производного понятия от очков                                               | важно     |
| B5  | статус матча кодами в `C1` (0/1/2) вместо структур / производных понятий                                                     | важно     |
| B6  | нет аксиом: команда не играет сама с собой; победитель — участник матча; каждая пара команд встречается ровно раз (круговой) | важно     |
| B7  | победитель у отменённого матча не запрещён; нет связи статуса и результата                                                   | важно     |
| B8  | `F2` «победы команды» используется нигде — ок; место команды невыразимо без порядка по очкам (допустимо как замечание)       | замечание |

## Ловушки

- «Диагностик нет — схема годится».
- Найти только стилистику (`card` в A1/A2) и пропустить смысловые дефекты.
- Переписать схему без запроса.

## Рубрика (0–2 за пункт)

1. Восстановлена задача схемы (из запроса) до разбора формул.
2. B1 найден (проверка термина против формулы, лучше — на КМ).
3. B2 найден (ничья).
4. B3 найден (различение сыгранных / запланированных).
5. B4–B5 найдены.
6. B6–B7 найдены (хотя бы два инварианта).
7. Находки подтверждены вычислением на КМ (хотя бы B1 или B3).
8. Отчёт: вердикт «не годится как есть», ранжирование, конкретные правки, без самовольной переделки.
