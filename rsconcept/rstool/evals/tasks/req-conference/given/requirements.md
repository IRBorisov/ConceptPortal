# ТЗ: подсистема рецензирования докладов конференции (фрагмент)

## 1. Общие положения

1.1. Подсистема предназначена для организации рецензирования докладов, поданных на конференцию.
1.2. Интерфейс должен быть удобным и понятным для всех категорий пользователей.

## 2. Доклады и рецензирование

2.1. Доклад подаёт один или несколько авторов. Автор указывает свою организацию; у человека может быть несколько организаций.
2.2. Председатель программного комитета назначает рецензентов доклада из числа членов программного комитета.
2.3. Член программного комитета не может рецензировать доклад, если он является его соавтором или работает в той же организации, что и кто-либо из авторов доклада (конфликт интересов).
2.4. Каждый доклад должен быть назначен не менее чем трём рецензентам.
2.5. Рецензент пишет на доклад одну рецензию с оценкой по шкале от −2 до +2.
2.6. Рецензию может написать только рецензент, назначенный на этот доклад.
2.7. Председатель видит список докладов, ожидающих рецензий: тех, у которых есть назначенный рецензент без написанной рецензии.
2.8. Доклад принимается, если на него написаны рецензии всех назначенных рецензентов, среди оценок нет отрицательных и есть хотя бы одна положительная.
2.9. Рецензии должны быть написаны в течение двух недель после назначения; просроченные рецензии выделяются цветом.

## 3. Прочее

3.1. Участники оплачивают регистрационный взнос через платёжный шлюз.
3.2. О назначении рецензента система уведомляет по e-mail.
3.3. Система хранит историю изменений рецензий.
