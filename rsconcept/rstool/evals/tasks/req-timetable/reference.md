# Скрытый эталон: req-timetable

Тип: КС по требованиям. Назначение: project.

## Требования к выразительным средствам

| id  | понятие                                                           | ref |
| :-- | :---------------------------------------------------------------- | :-- |
| E1  | занятие как сущность (дисциплина, преподаватель, аудитория, пара) | 2   |
| E2  | группы занятия (многозначно: поток)                               | 3   |
| E3  | вид занятия: лекция / практика                                    | 3   |
| E4  | свободные аудитории в пару                                        | 6   |
| E5  | окна группы                                                       | 7   |
| E6  | нагрузка преподавателя                                            | 8   |
| E7  | суммарная численность групп занятия                               | 9   |

## Инварианты

| id  | правило                                            |
| :-- | :------------------------------------------------- |
| I1  | практика — ровно одна группа                       |
| I2  | нет двух занятий у группы в одну пару              |
| I3  | нет двух занятий у преподавателя в одну пару       |
| I4  | нет двух занятий в аудитории в одну пару           |
| I5  | преподаватель ведёт только закреплённые дисциплины |
| I6  | нагрузка ≤ 20                                      |
| I7  | вместимость ≥ суммарной численности групп          |

## Различения

- V1 лекция-поток ≠ практика (структурно: одна группа vs несколько).
- V2 свободная аудитория в пару ≠ аудитория без занятий за неделю.

## Ловушки

- Видовое вместо родового: занятие как кортеж (группа, преподаватель, аудитория, пара) — тогда поток превращается в несколько «занятий» и I4 ложно срабатывает на поточной лекции (или его ослабляют). Эталон: занятие — `X#` с отношением «группы занятия».
- I7 требует суммы численностей; в ЯРЭ нет суммы по множеству. Честное решение: открытый вопрос / ограничение языка либо выражение через рекурсию `R{}` по подмножествам; подмена «вместимость ≥ численности каждой группы» — ослабление, если не записано как решение.
- Окна (E5) требуют порядка на парах → пара как `Z×Z` (день, номер) или `C#`; пары как `X#` делают E5 невыразимым.
- Пересказ п. 10–11; не названо невыразимое («история замен», «дата занятия»).
- `card(...) > 0` вместо `≠ ∅`.

## Рубрика (0–2 за пункт)

1. Постановка: назначение, исключения, невыразимое.
2. Вопросы пользователю до формализации.
3. Покрытие E1–E7.
4. Инварианты I1–I7 (I7 — выражен или честно помечен как невыразимый средствами языка).
5. Различения V1–V2.
6. Ядро: занятие — сущность с отношением к группам; пары с порядком.
7. Проверка смысла на КМ: поточная лекция проходит I4, нарушение I2/I7 ловится.
8. Честный отчёт.
