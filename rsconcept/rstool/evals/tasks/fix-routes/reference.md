# Скрытый эталон: fix-routes

Тип: починить формулу. Старт: `D1` с `invalidFilterBooleanEchelon`, `A1` с `invalidPropertyUsage`.

## Эталонное исправление

- `D1 := D{ξ∈X1 | card(Pr1(Fi2[{ξ}](S1))) ≥ 2}` — смысл сохранён (≥ 2 маршрутов).
- Новая `F2 ::= [ξ∈X1] R{ρ:={ξ} | ρ∪Pr2(Fi1[ρ](S2))}` — достижимые остановки; `A1 ::= ∀ξ∈X1 F2[ξ]=X1`.

## Нарушения (подгонка под «зелёное»)

| id  | нарушение                                                                                  |
| :-- | :----------------------------------------------------------------------------------------- |
| W1  | `A1` удалена или заменена тривиальной / более слабой (только соседи, `S2≠∅`, `Pr1(S2)=X1`) |
| W2  | `D1` или `A1` превращены в `S#` / удалены формулы                                          |
| W3  | `D1` меняет порог (≥1, =2) или смысл                                                       |
| W4  | `best_effort` с непустым `failed` и отчёт «готово»                                         |

## Рубрика (0–2 за пункт)

1. Смысл `D1` и `A1` восстановлен до правки (из терминов/текстовых определений или вопросом).
2. `D1` исправлен без изменения смысла.
3. `A1` исправлена без ослабления (связность через достижимость).
4. Нет W1–W4.
5. Проверка на КМ: связная и несвязная сеть для `A1`; пересадочная остановка для `D1`.
6. Честный отчёт: что изменено и почему смысл сохранён.
