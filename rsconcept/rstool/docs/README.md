# Документация rstool

Краткая справка для агентов.

**Процесс работы** — скилл-маршрутизатор `../skills/rstool/SKILL.md`: он определяет сценарий и этап и называет скилл этапа. Здесь — метод, правила языка и предметной области.

## Какой файл читать

- **METHOD.md** — метод концептуализации: этапы, гейты, вопросы пользователю, защита от подгонки, синтез; соответствие терминов учебника и Portal.
- **BRIEF.md** — бриф схемы: поля, сценарии подписями, проверка `check-brief`. JSON-схема — **brief.schema.json**.
- **DOMAIN.md** — термины Portal: конституента, неопределяемые и производные понятия, ядро/тело КС, интерпретация, синтез / встраивание, ОСС.
- **CONCEPTUAL-SCHEMA.md** — проектирование и ревью концептуальных схем (в т.ч. терм-функция вместо множества пар, (не)пустота через `∅`).
- **CONSTITUENTA.md** — структура и правила конституент.
- **BASE-SELECTION.md** — выбор основания: `X#`, `C#` или `Z`.
- **SYNTAX.md** — синтаксис ЯРЭ: операторы, генераторы `D{}`/`I{}`/`R{}`, кванторы, `F#`/`P#`.
- **CONSTRUCTIONS.md** — объяснение формул и конструкций человеку (карточки, разбор снаружи внутрь).
- **TYPIFICATION.md** — типизация (`AnalysisResult.type`, `valueClass`).
- **MODEL-TESTING.md** — проверка семантики определений на маленьких концептуальных моделях.
- **DIAGNOSTICS.md** — диагностики анализа и способы исправления ошибок.
- **PORTAL-API.md** — указатель REST Portal: **PORTAL-READ.md** (ссылка → API, доступ, поиск, импорт), **PORTAL-PUBLISH.md** (протокол публикации, лимиты), **PORTAL-MODELS.md** (интерпретации), **PORTAL-OSS.md** (граф ОСС).

Контракт агента `rstool` (library / stdio / MCP) и примеры — `../skills/rstool-runtime/REFERENCE.md`, `EXAMPLES.md` (на русском).
