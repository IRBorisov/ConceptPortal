Ребро в узел 0 не находится и добавляется повторно

воспроизведено

rsconcept/domain/src/graph/graph.ts:147

return !!sourceNode.outputs.find(id => id === destination);

Уверенность: точно. Категория: Прочее.

Сценарий. Создать new Graph([[1, 0]]), проверить hasEdge(1, 0), затем ещё раз вызвать addEdge(1, 0).

Ожидаемое и фактическое. hasEdge возвращает false, а outputs становится [0, 0]. Ожидается true и единственное ребро.

Причина. find возвращает сам найденный id. Значение 0 преобразуется в false.

Ущерб и условия. Узел 0 допустим для числового Graph. Проверка наличия и удаление рёбер теряют согласованность. Для положительных id этот сценарий не проявляется.

Что сделать. Проверять наличие через some или includes. Проверить также пустую строку для строкового NodeID и обходы графа, использующие find как булево значение.

Приёмка. Повторное добавление ребра с destination=0 не меняет outputs и inputs; hasEdge возвращает true.

Проверка: repro.test.ts · graph detects an edge whose destination is zero. Ожидаемое поведение нарушено; штатный набор тестов эту ошибку не выявил.
